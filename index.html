웹 앱 URL 설정 안내

구글 앱스 스크립트(Google Apps Script) 배포 후 생성된 URL을 아래 코드의 SCRIPT_URL에 붙여넣으면 시트 자동 수집 및 이메일/문자 알림이 작동합니다.

GitHub Pages 배포 & 구글 연동 안내 (구글 로그인 없이 작동)

1. GitHub Pages로 웹페이지 무료 배포 방법

  1. GitHub에 로그인 후 새 Repository를 생성합니다 (예: mate-edu).
  2. 이 HTML 파일의 이름을 index.html로 저장하여 업로드합니다.
  3. Repository 메뉴에서 Settings > Pages 항목으로 이동합니다.
  4. Build and deployment의 Branch를 main (또는 master) 및 / (root)로 선택하고 Save를 누릅니다.
  5. 약 1~2분 후 https://사용자ID.github.io/mate-edu/ 형태의 공개 URL이 생성됩니다. 이 링크를 공유하시면 됩니다!

2. 구글 시트 연동 설정 (로그인 없이 누구나 신청)

  1. 구글 시트 "공익활동메이트 신청자 명단"을 엽니다.
  2. 상단 메뉴 [확장 프로그램] > [Apps Script]를 클릭합니다.
  3. 기존 코드를 모두 지우고 아래 제공된 자바스크립트 코드를 복사해서 붙여넣습니다.
  4. 우측 상단 [배포] > [새 배포] 클릭 ⚙️(톱니바퀴)에서 [웹 앱] 선택
  5. 다음 사용자 권한으로 실행: 나(Me), 액세스 권한이 있는 사용자: 모든 사용자(Anyone)로 설정 필수! (구글 비로그인 신청용)
  6. 배포 후 생성된 웹 앱 URL을 복사하여 본 코드의 SCRIPT_URL 부분에 넣어주세요.
// [구글 앱스 스크립트 코드] - 구글 시트 -> 확장 프로그램 -> Apps Script 에 붙여넣기

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // 시트에 신청 데이터 행 추가
    sheet.appendRow([
      data.applyDate,
      data.userName,
      data.userPhone,
      data.organization || '개인',
      data.session1 ? 'O' : 'X',
      data.session2 ? 'O' : 'X',
      data.inquiry || '-',
      data.privacyConsent ? '동의' : '미동의',
      data.mediaConsent ? '동의' : '미동의',
      new Date()
    ]);

    // 센터 알림 이메일 (aypublic@aypublic.or.kr)
    var centerEmail = "aypublic@aypublic.or.kr";
    var emailSubject = "[신청알림] 공익활동메이트 교육 신청 - " + data.userName + "님";
    var emailBody = "공익활동메이트 교육 신청서가 접수되었습니다.\n\n"
                  + "• 신청일자: " + data.applyDate + "\n"
                  + "• 신청자명: " + data.userName + "\n"
                  + "• 연락처: " + data.userPhone + "\n"
                  + "• 소속/단체: " + (data.organization || '개인') + "\n"
                  + "• 1회차 참여: " + (data.session1 ? '신청' : '미신청') + "\n"
                  + "• 2회차 참여: " + (data.session2 ? '신청' : '미신청') + "\n"
                  + "• 문의사항: " + (data.inquiry || '없음') + "\n";
                  
    MailApp.sendEmail(centerEmail, emailSubject, emailBody);

    // [선택] 신청자 휴대폰 문자로 안내 발송 (Solapi/Aligo 등 API 연동 서비스 활용)
    // UrlFetchApp.fetch("https://api.solapi.com/...", { method: "post", ... });

    return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({"result": "error", "error": err.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
